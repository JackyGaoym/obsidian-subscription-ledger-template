# P0 订阅 Logo 素材索引

本目录收录 P0 清单对应的订阅图片，共 79 个实体文件，覆盖 80 个订阅项目。印象笔记与 Evernote 共用 `evernote.png`。

- 品牌图形保持原始比例、颜色和结构，只统一画布、尺寸、安全边距与背景适配。
- 基础素材来自现有订阅图片、Simple Icons、对应服务的 App Store 官方应用图标或 Iconify 品牌图标。
- 全部素材已统一输出为 1024 × 1024、sRGB PNG，主体视觉范围约占画布 62.5%，四周保留安全边距。
- 79 张全部使用真实透明背景，画布不写入额外底色；按订阅页面固定的浅色纸张背景验收。
- 文件名使用稳定的小写英文键，套餐名和历史别名由订阅数据负责匹配。

> 品牌名称与标识归各自权利人所有，仅用于帮助用户识别和记录订阅服务。本项目与相关品牌不存在隶属、赞助或合作关系。

## 来源入口

- Simple Icons：`https://cdn.simpleicons.org/<slug>`
- Apple Search API：`https://itunes.apple.com/lookup?bundleId=<bundle-id>&country=<country>`
- Iconify：`https://api.iconify.design/<collection>/<icon>.svg`
- HBO Max Brand Portal：`https://brand.hbomax.com/quick-downloads`

更新某个 Logo 时，优先保持原文件名不变，这样订阅数据中的 `logo_key` 不需要跟着迁移。
